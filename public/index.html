자바스크립트의 직관적인 확장,
KRJS 런타임.

Babel AST 기반으로 동작하며, 자연스러운 한국어 키워드로 코딩할 수 있는 모던 프로그래밍 언어 다이알렉트입니다.

npm에서 설치 GitHub 레포지토리

아키텍처 개요

단순 치환 방식이 아닌, 완전한 Babel AST(Abstract Syntax Tree) 파싱을 거쳐 안전하고 효율적인 순수 자바스크립트로 변환됩니다.

  • 안정적인 동기/비동기 흐름 제어
  • 전역 CLI 툴셋 krnode 탑재

패키지 설치

Node.js 환경에서 글로벌 패키지를 설치하여 즉시 사용하실 수 있습니다.

npm install -g @asanalidev/krjs

소스 코드 예시 (main.krjs)

직관적인 한국어 키워드(상수, 함수, 로그 등)를 활용한 클린 코드 구조입니다.

// main.krjs
상수 메시지 = "안녕하세요, KRJS!";

함수 출력(대상) {
    로그(대상 + " — 정상 작동 중입니다.");
}

출력(메시지);

asanaliopensource/krjs-vscode
